# Changelog

## 0.3.0 — 2026-09-20

First public open-source release of the Omarchy Kids experiment.

- Native YouTube browsing with approved-channel filtering and independent checks for direct videos and embeds.
- Shorts blocking and controls for recommendations, comments, search, end screens, live chat, notifications and autoplay.
- Direct navigation to Subscriptions without an intermediate app page.
- Omarchy parent menu with password protection, 15-minute unlock, and **Close** for early locking.
- Authenticated CLI, JSON responses and explicit temporary agent access.
- Root-owned local service, persisted guessing limits and per-device signed Chromium extension installed through managed policy.
- Ready-to-install Omarchy archive, Git installation, MIT license, documentation and automated checks.

Chromium on Omarchy is tested. Brave/Chrome compatibility, stronger playback enforcement and whole-device lockdown remain follow-up work. Advertising is not blocked.
