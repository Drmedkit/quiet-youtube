# Roadmap

These are candidate areas for contributions, not promised delivery dates.

- Harden playback enforcement against arbitrary page JavaScript and document verified bypass coverage.
- Design whole-device child-account controls for alternate browsers, terminals and administrative access.
- Test Google Chrome and Brave, including installation, managed policy and update behavior.
- Broaden coverage for YouTube layout changes, mobile URLs and signed-in Subscriptions.
- Improve channel onboarding, including a reviewed bulk-approval workflow. No Google subscription import exists today.
- Add automated Omarchy panel checks for authentication, expiry and update behavior.
- Improve release automation and build provenance while retaining a no-Node installation path.

Ad blocking and DNS filtering are outside the current scope. Changes should keep YouTube's native browsing experience and a clear parent-controlled allowlist.
